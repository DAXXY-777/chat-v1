# Foundation AI

A learning-focused project for understanding how modern AI applications are built.

The purpose of this project is to recreate the core workflows of conversational AI systems (such as chat interfaces, conversation management, authentication, and model integration) to gain a deeper understanding of AI application architecture. It is intended as a reusable foundation for future AI projects and SaaS applications.

> **Educational purpose only.** This project is built to learn AI application architecture and software engineering concepts.

## Current Stack

* Streamlit
* Python
* OpenAI-compatible APIs

## Planned Stack

* SvelteKit
* FastAPI
* PostgreSQL
* Modern authentication solution

## Deployment

The application is being designed to be portable and easy to deploy, with support for environments such as:

* Docker
* Cloudflare
* Desktop (.exe via WebView)
